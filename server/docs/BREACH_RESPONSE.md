# Data Breach Response Protocol (DPDP Act)

## 1. Identification & Containment
- Upon detecting a breach, immediately isolate the affected system.
- Preserve logs and evidence for forensic analysis.
- Record the date and time the breach was discovered.

## 2. Assessment (Within 24 Hours)
- Determine the nature of the breach (e.g., unauthorized access, data leak).
- Identify the categories and approximate number of data principals affected.
- Assess the probable consequences of the breach.
- Document findings in an incident report.

## 3. Notification to Data Protection Board (Within 72 Hours)
- Prepare a preliminary report containing:
  - Nature of the breach
  - Categories and approximate number of data principals affected
  - Probable consequences
  - Measures taken or proposed to address the breach
- Submit this report to the Data Protection Board of India through their online portal.

## 4. Notification to Affected Individuals (Within 72 Hours)
- Draft a clear, plain-language notice for affected users.
- The notice must include:
  - Description of the breach
  - Possible consequences
  - Steps users can take to protect themselves
  - Contact information for assistance (hello@peekmoment.com)
- Send via email (if available) or publish on the website if direct contact is not possible.

## 5. Post-Incident Review (Within 7 Days)
- Conduct a root cause analysis.
- Implement additional safeguards to prevent recurrence.
- Update this protocol based on lessons learned.
